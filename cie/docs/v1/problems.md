# Problems

- We currently have no way to clearly assess whether an agent is performing well or poorly.
- We need visibility into whether the agent is:
  - Following instructions.
  - Making the right tool calls.
  - Helping the guard complete their tasks.
  - Satisfying the client's success criteria.
- These indicators should determine whether performance is **good** or **bad**, rather than relying on a vague “okay” rating.
